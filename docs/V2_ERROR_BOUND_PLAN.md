# V2 오차 상한 시제품: 계획과 성공·중단 기준 (봉인)

이 문서는 V2 코드를 쓰기 **전에** 커밋한다. 결과를 본 뒤 기준을 고치지 않는다.

- Gate 2A는 CLOSED / PARTIAL로 봉인되어 있다(`tests/test_gate2a_sealed.py`). V2는 Gate 2A의 파일을 **읽기·import만** 하고 고치지 않는다.
- 이것은 **시제품**이다. 성공하더라도 바로 규칙이 되지 않는다. 설계자가 승인하면 별도 문서 `BINARY64_TOLERANCE_RULE_V2`로 봉인한다.

## 0. 왜 V2인가 (이미 알려진 사실을 공개)

V2 방법은 Gate 2A에서 진단한 V1의 고장 원인을 겨냥해 골랐다.
- V1은 오차를 성분별 절댓값으로 전파한다.
- Verlet의 오차 동역학은 회전에 가깝다. 절댓값을 쓰면 그 회전이 매 step 약 1.019배 성장으로 바뀐다.
- 그 결과 규칙 궤도와 혼돈 궤도의 인증 범위가 둘 다 약 1,500–1,800 step으로 비슷하게 나왔다.

**방법을 고른 이유가 알려진 고장인 것은 정당하다.** 금지하는 것은 **기준값이나 구현 세부를 V2 결과를 보고 맞추는 것**이다.

## 1. 방법 (V2 = 단계 안 affine 산술 + 단계 사이 Lohner식 기저 교체)

참값 s(같은 이산 프로그램의 정확 산술 실행값)에서 계산값까지의 오차를 δ = ŝ − s라 한다.

**① 단계 안: 연산 단위 affine 산술**
- 한 step의 입력 오차를 δ = C·ξ (ξ ∈ [−1, 1]⁴)로 표현한다. C는 4×4 행렬이다.
- 각 레지스터의 오차를 "ξ에 대한 선형식 + 상자(대칭 반경)"로 들고 간다.

| 연산 | 정확한 관계 | 선형 부분 | 상자에 더하는 것 |
|---|---|---|---|
| ADD / SUB | δz = δx ± δy + r | 계수끼리 더하기·빼기 | 상자 합 + ρ |
| NEG | δz = −δx | 계수 부호 바꿈 | 상자 그대로 |
| MUL | δz = x̂·δy + ŷ·δx − δx·δy + r (항등식) | x̂·(y의 계수) + ŷ·(x의 계수) | \|x̂\|·상자_y + \|ŷ\|·상자_x + rad(δx)·rad(δy) + ρ |
| CONST | δ = ĉ − c (정확히 앎) | 없음 | \|ĉ − c\| |

- ρ는 V1과 같은 **정확한 국소 반올림 오차**다.
- 계수를 float로 계산할 때 생기는 반올림은 계수마다 \|c\|·2⁻⁵² + 2⁻¹⁰⁷⁴ 이하이므로, 그만큼을 상자에 더한다.
- 상자 계산은 모두 위로 반올림한다.

**② 단계 사이: 기저 교체** (Lohner 1987 계열의 QR 방식. 이 Lab은 원문을 확인하지 않았으며, 수학은 아래에 스스로 적었다)
- step이 끝나면 δ_out ∈ M·ξ + [−w, w]이다. M은 4×4 계수 행렬, w는 상자 반경이다.
- M의 열을 크기 순으로 정렬해 float QR을 하고, 그 Q를 새 기저 A로 삼는다. A는 정확히 직교하지 않아도 된다. 역행렬을 **정확한 유리수**로 계산하기 때문이다.
- 새 반경 r'ᵢ = Σⱼ \|(A⁻¹M)ᵢⱼ\| + Σⱼ \|A⁻¹ᵢⱼ\|wⱼ를 정확히 계산한 뒤 위로 반올림한다.
- 다음 step의 입력은 C = A·diag(r')이다. float 곱의 반올림은 다음 step 상자에 더한다.
- 성분별 상한은 Eᵢ = Σⱼ \|Aᵢⱼ\|·r'ⱼ로 보고한다(위로 반올림).

**엄밀성 논증:**
- 모든 단계가 정확한 항등식이거나 위로 반올림한 부등식이다.
- 1차 근사로 버리는 항이 없다. MUL의 δx·δy 항은 상자에 넣는다.
- 기저 교체 δ ∈ A·(A⁻¹M ξ + A⁻¹[−w, w])는 집합 포함 관계로서 정확하다.

## 2. 실험

- **SUT:** Gate 2A와 같은 프로그램과 같은 binary64 궤적(결정론). h = 1/64, N = 10⁵.
- **주 궤도:** Gate 2A에서 선택된 규칙 궤도 (1/4, 1/8), 혼돈 궤도 (1/2, 1/4).
- **hold-out 궤도 (과적합 방지):** Gate 2A 후보 목록에서 쓰이지 않은 4개 — 규칙 (1/8, 1/4), (1/4, 0), 혼돈 (7/16, 5/16), (9/16, 1/8). 건전성 기준을 똑같이 적용하고, 유용성 수치는 보고만 한다.
- **측정 (궤도마다):**
  - V2 상한의 증가 곡선. 기록 지점 n = 10, 100, 10³, 10⁴, 5×10⁴, 10⁵
  - V2 상태 인증 한계(V1과 같은 정의: 상한 최댓값 ≥ 상태 크기 최댓값이 되는 첫 step)
  - 같은 실행에서 계산한 V1 상한(비교용)
  - 120자리 mpmath 추정 실제 오차(ESTIMATE, 상한 아님)
  - 비용
- **보조 측정 (주 궤도만, 성공 기준과 무관):** V2 상한으로 다시 판정한 K1 시간 역전(L ∈ {10², 10³, 10⁴, 10⁵}). 그리고 결함 D2를 L = 1000에서 다시 판정. 둘 다 Gate 2A 결과를 바꾸지 않는 **새 측정**이다.

## 3. 성공·중단 기준 (V2 코드 작성 전 고정)

**건전성: 하나라도 실패하면 즉시 중단, V2 = FAIL**

| ID | 기준 |
|---|---|
| V2-S1 | 엄밀성 단위 시험: MUL·ADD 규칙과 기저 교체가 무작위가 아닌 고정 사례에서 상자의 모든 꼭짓점을 포함한다 |
| V2-S2 | 정확 구간 재실행(Gate 2A K4와 같은 방식, 8 step, 주 궤도 n₀ ∈ {0, 50000, 99992}): 실제 오차 ≤ V2 상한 |
| V2-S3 | 모든 궤도(주 2 + hold-out 4), 모든 기록 지점에서 V2 상한 ≥ 120자리 추정 실제 오차. 추정은 엄밀하지 않지만, 상한이 그보다 작으면 사실상 반증으로 본다 |

**유용성: 건전성을 모두 통과한 뒤에만 판정**

| ID | 기준 | 미달 시 |
|---|---|---|
| V2-U1 | 주 규칙 궤도의 V2 인증 한계 ≥ **17,790 step** (V1의 1,779 step × 10, 한 자릿수 향상) | **중단:** "이 방식으로는 실질적 개선 없음"으로 보고하고 이 방향을 접는다 |
| V2-U2 | V2가 두 궤도를 구별: 규칙 궤도 인증 한계 ≥ 혼돈 궤도의 10배, 또는 규칙 궤도만 N(=10⁵)까지 유지 | 부분 성공으로 보고 |
| V2-C | 비용: 주 궤도 2개 + hold-out 4개 + 보조 측정 전체가 클라우드에서 60분 이하 | 초과하면 측정은 보고하고, Gate 2B 적용 전에 비용 문제를 별도로 다룬다 |

**판정:**
- V2-S 모두 + U1 + U2 + C 충족 → **PASS**. 설계자에게 규칙 V2 봉인을 제안한다.
- S 모두 + U1, U2 미달 → **PARTIAL**
- S 모두 + U1 미달 → **STOP**
- S 하나라도 실패 → **FAIL**

## 4. 금지

- V2 결과를 본 뒤 기준값, 기록 지점, hold-out 궤도, 기저 교체 세부(정렬 규칙 등)를 바꾸는 것.
  구현 결함을 고치는 것은 허용하되, 사후 감사 기록을 남긴다(Gate 0의 Muller 감사와 같은 형식).
- V2 상한을 연속 궤적(방법 층 B)의 인증으로 쓰는 것. V2도 반올림 층(A)만 다룬다.
- Gate 2A 파일 수정. 해시 시험이 막는다.

## 5. 미리 공개하는 한계

- 혼돈 궤도에서는 실제 오차 자체가 지수적으로 자란다. 그러므로 V2도 인증 한계가 짧을 수 있다. 그것은 실패가 아니라 정직한 결과다.
- 기저 교체에서 새 반올림 상자를 A⁻¹로 감쌀 때 매 step 약간의 wrapping이 남는다. 그래서 V2 상한도 실제 오차보다 클 것이다. 얼마나 큰지가 측정 대상이다.
- 이 방법은 분기 없는 직선형 프로그램을 전제로 한다(V1과 같다).
