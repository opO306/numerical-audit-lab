# binary64 물리 검사 허용 오차 규칙 V1 (봉인, Gate 2 대상 선정 전)

이 문서는 **Gate 2 후보를 조사하기 전에** 커밋한다. Gate 2 대상을 본 뒤 이 규칙을 그 대상에 맞춰 고치지 않는다.
고쳐야 하면 V2를 만들고 이유를 남긴다.

## 0. 원칙

**고정 epsilon(1e-8, 1e-12 등)은 쓰지 않는다.**

판정식은 `|R| ≤ B` 하나다.
- R: 검사 잔차(residual). 검사기가 SUT의 binary64 출력값을 **정확한 유리수로** 넣어 계산한다. 검사 쪽에서는 반올림이 생기지 않는다.
- B: "SUT의 반올림만으로 R이 0에서 얼마나 벗어날 수 있는가"의 **엄밀한 상한**. 아래 규칙으로 실행마다 유도한다.

| 판정 | 뜻 |
|---|---|
| PASS | \|R\| ≤ B: 잔차가 수치 반올림으로 설명된다 |
| FAIL | \|R\| > B: 반올림으로 설명할 수 없다(논리·모델 결함, 또는 상한 유도의 결함) |
| REFUSED | 상한을 정할 수 없거나 의미가 없다: ① 나누는 수의 오차 구간이 0을 포함, ② 실행이 멈춤(overflow 등), ③ 단계 반올림 감사(N1)가 실패, ④ B가 검사량의 크기 S 이상(검사할 힘이 없음), ⑤ 2종 검사인데 방법 오차 상한이 없음 |

## 1. "참값"의 정의

참값 = **같은 프로그램을 정확한 입력 리터럴로 정확 산술에서 실행한 값**이다.
- 이 규칙이 설명하는 것은 binary64 반올림뿐이다.
- 프로그램 자체의 논리 오류나 이산화(시간 간격) 오차는 반올림이 아니다. 그런 차이는 B에 들어가지 않으므로 FAIL로 드러나야 한다.
  단 2종 검사는 예외이며 3절에서 다룬다.

## 2. 연산별 오차 상한과 전파 (실행 기록을 따라 한 단계씩)

레지스터마다 e = |계산값 − 참값|의 상한을 둔다. **모든 계산은 정확한 유리수**로 하거나, 위로 반올림하는 구간 산술로 한다.

**국소 반올림 오차 ρ** (두 방식 중 하나, 실행마다 명시)
- (a) 정확한 국소 오차: ρ = |ẑ − (x̂ op ŷ)|. 계산된 입력값에 정확한 연산을 한 값과 비교한다. 가정이 없다.
- (b) 반 ulp: ρ ≤ ½·ulp(ẑ). **N1(독립 채점기의 단계 반올림 감사)이 그 단계를 PASS로 판정한 경우에만** 쓴다.

**전파 규칙** (x̂, ŷ: 계산값, eₓ, e_y: 그 오차 상한)

| 연산 | 오차 상한 e_z |
|---|---|
| CONST c (리터럴 c는 정확) | \|ĉ − c\| (+ 다른 실행의 출력을 입력으로 받으면 그 실행의 e를 씨앗으로 더함) |
| ADD, SUB | eₓ + e_y + ρ |
| NEG, ABS | eₓ |
| MUL | \|x̂\|e_y + \|ŷ\|eₓ + eₓe_y + ρ |
| DIV | e_y < \|ŷ\|일 때만: (\|x̂\|e_y + \|ŷ\|eₓ) / (\|ŷ\|(\|ŷ\| − e_y)) + ρ. 아니면 REFUSED |
| SUM, DOT (한 번 반올림) | Σ(\|x̂ᵢ\|e_{yᵢ} + \|ŷᵢ\|e_{xᵢ} + e_{xᵢ}e_{yᵢ}) + ρ (SUM은 Σeᵢ + ρ) |
| SQRT | x̂ > eₓ일 때: eₓ / (√(x̂ − eₓ) + √x̂) + ρ, 아니면 √eₓ + ρ. √는 아래쪽 유리수 상한으로 바꿔 계산 |
| EXP | exp(x̂ + eₓ)·eₓ + ρ. exp는 위쪽 유리수 상한으로 계산 |

- 모두 1차 근사가 아니라 **정확한 부등식**이다. 예: MUL의 eₓe_y 항을 버리지 않는다.
- 비교·분기(CMP)는 V1에서 다루지 않는다. 분기가 있는 프로그램에서는 분기마다 여유(margin)가 오차 상한보다 커야 한다. 이를 확인하는 규칙이 없으므로 **분기가 있는 실행은 REFUSED**다.

## 3. 검사의 두 종류

| 종류 | 정의 | 허용 범위 |
|---|---|---|
| **1종** | 프로그램이 정확 산술에서 **정확히** 만족하는 관계. 예: 충돌 1회의 보존 법칙, 대칭 변환, Verlet의 시간 역전, 쌍힘 Verlet의 선형 운동량 | B = 반올림 상한만 |
| **2종** | 정확 산술에서도 **방법 오차** 때문에 근사적으로만 맞는 관계. 예: 시간 적분의 에너지 보존 | B = 반올림 상한 + **방법 오차 상한**. 방법 오차 상한은 ① 인용한 해석적 정리, 또는 ② 같은 프로그램의 정확 산술 실행값으로만 얻는다. 둘 다 없으면 REFUSED(경향만 참고 정보로 보고) |

검사를 1종으로 분류하려면 근거(유도 또는 정확 산술 시험)가 있어야 한다. 근거가 없으면 2종으로 다룬다.

## 4. 검사식으로의 전파

SUT 출력 ŷ의 오차 상한 E가 2절로 정해졌다고 하자. 검사기는 잔차 R을 정확히 계산하고, 상한 B는 다음처럼 정한다.

- **선형 검사식** R = Σ cᵢ ŷᵢ − (정확한 상수): B = Σ \|cᵢ\| Eᵢ
- **이차 검사식**(예: 운동에너지): \|ŷ² − y²\| ≤ E(2\|ŷ\| + E)
- **일반 다항·유리식**: 상자 [ŷ ± E] 위에서 검사식을 정확한 유리수 구간 산술로 평가한 폭으로 상한을 잡는다
- **변환(메타모픽) 검사** \|out_T − T(out)\|: T가 정확한 선형 변환이면 B = E_T + \|T\|E. 여기서 \|T\|는 성분별 절댓값 행렬이다.
  변환한 입력을 binary64로 다시 표현할 때 생기는 오차는 그 실행의 CONST 단계에서 2절에 따라 자동으로 들어간다
- **다른 실행의 출력을 입력으로 받는 검사**(시간 역전 등): 입력 CONST에 앞 실행의 E를 씨앗으로 넣는다

## 5. Gate 1 검사에 적용한 유도 (예시, 결과에서 거꾸로 맞춘 것이 아님)

E₁, E₂: 충돌 후 속도 성분별 오차 상한, E_k: KE′의 오차 상한. 모두 2절 규칙(ρ = 방식 a)으로 구한다.

| 검사 | 잔차 R (정확 계산) | 상한 B |
|---|---|---|
| C1 참조 | ŵ − w_ref (성분별) | E (성분별) |
| C3 운동량 | Σmᵢŵᵢ − Σmᵢvᵢ (x, y 각각) | m₁E₁ + m₂E₂ (성분별) |
| C4 KE | Σmᵢ\|ŵᵢ\|² − Σmᵢ\|vᵢ\|² | Σᵢ mᵢ Σ_c Eᵢc(2\|ŵᵢc\| + Eᵢc) |
| C4b 보고 KE | KÊ′ − KE_before | E_k |
| C5 교환 | ŵ^swap − swap(ŵ) | E^swap + swap(E) |
| C6 이동 | ŵ^shift − ŵ | E^shift + E |
| C7 회전 | ŵ^rot − R₉₀ŵ | E^rot + (E_y, E_x) |
| C8 boost | 속도: ŵ^V − (ŵ+V), KE: KÊ′^V − (KÊ′ + V·P̂ + ½M\|V\|²) | 속도: E^V + E. KE: E_k^V + E_k + Σ_c\|V_c\|(m₁E₁c + m₂E₂c) |
| C9 시간 역전 | ŵ^rev − (−v), KÊ′^rev − KÊ′ | 역방향 실행의 입력 속도에 E를 씨앗으로 넣어 얻은 E^rev (+ E_k) |
| C10 성질 | (ŵᵢ−vᵢ)×d, (ŵ₁−ŵ₂)·d + (v₁−v₂)·d | \|d_y\|Eᵢx + \|d_x\|Eᵢy, Σ_c\|d_c\|(E₁c + E₂c) |

충돌 1회 계산이므로 모든 검사가 1종이다.

## 6. 규칙 검증 (Gate 1 binary64 실행, 봉인 전 시제품)

봉인 전에 이 규칙을 Gate 1 binary64 실행에 시제품으로 적용했다. Lab 코드가 아닌 작업용 스크립트이며, 결과 숫자만 여기 기록한다.

| 확인 항목 | 결과 |
|---|---|
| 올바른 프로그램(M0)을 binary64로 실행, 6개 시나리오 × 10개 검사 | **오경보 0건** (허용 오차가 없을 때는 S1에서만 7건) |
| 버그 M1–M7의 탐지표 | 비교한 46개 (버그, 시나리오) 행 모두 **정확 산술 탐지표와 같음** (M5의 S2·S5는 교환 실행이 멈춰서 제외) |
| 오차 상한의 크기 | 0 (S2, 모두 작은 정수) ~ 3.4×10⁻¹⁰ (S6, 좌표 10⁶에서 위치 반올림) |
| 반올림 결함 R1 | 물리 검사는 전부 PASS. ρ = 방식 (a)가 실제 국소 오차를 쓰기 때문이다. **그래서 0절의 REFUSED ③(N1 실패 시 물리 판정 무효)이 필요하다** |

## 7. 대체 방법 (2절 방식이 너무 비쌀 때)

1. **구간 재실행:** 같은 프로그램을 바깥쪽으로 반올림하는 구간 산술(mpmath.iv)로 다시 실행해 참값을 감싼다. 2절과 같은 의미이고, 비용만 다르다.
2. **정확 재실행:** EXACT 프로필로 프로그램 전체를 실행한다. 짧은 프로그램에서 가장 강하다.
3. **표본 정확 구간:** 긴 실행의 일부 구간만 정확 재실행한다. 결과는 `SAMPLED`로 표시하며, **전체 PASS로 올리지 않는다.**

## 8. 금지

- 고정 epsilon, "보기에 충분히 작다"는 판단
- Gate 2 결과를 본 뒤 상한 식이나 씨앗·분류를 바꾸는 것
- 검사기 쪽에서 binary64나 float를 쓰는 것. 잔차는 언제나 정확하게 계산한다
- 1차(선형화) 오차 추정을 상한이라고 부르는 것. 그런 값은 `ESTIMATE`로만 보고한다
- 2종 검사를 근거 없이 1종으로 분류하는 것

## 9. 한계

- 길거나 혼돈적인 실행에서는 B가 빠르게 커진다. B가 검사량 크기를 넘으면 REFUSED이고, 그것도 정직한 결과다. "몇 단계까지 인증 가능한가"를 보고한다.
- 방식 (a)는 단계마다 정확 유리수 연산을 해야 하므로 비싸다. 큰 실행에서는 방식 (b)나 구간 재실행을 쓴다.
- 분기가 있는 프로그램은 V1 범위 밖이다.
- 이 규칙은 반올림만 다룬다. 물리 모델이 현실과 맞는지는 별개 질문이다.
