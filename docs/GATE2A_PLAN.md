# Gate 2A — Published-model reproduction and multi-layer verification: 계획 (봉인)

이 문서는 Hénon–Heiles 코드를 쓰기 **전에** 커밋한다. 결과를 본 뒤 고치지 않는다.

- **이 단계는 외부 코드 감사가 아니다.** 공개된 물리 모형을 바탕으로 Lab 안에 최소한의 SUT를 새로 구현해(clean-room), 여러 층으로 검증한다.
  제3자 구현 감사는 Gate 2B에서 따로 한다.
- 허용 오차 규칙: [BINARY64_TOLERANCE_RULE_V1.md](BINARY64_TOLERANCE_RULE_V1.md) (봉인, 변경 없음).

## 0. 사용하는 공개 정보 (독립 출처로 확인한 것만)

| 정보 | 출처 |
|---|---|
| 해밀토니안 H = ½(p_x² + p_y²) + ½(x² + y²) + x²y − y³/3 | Hénon & Heiles, *Astron. J.* 69, 73 (1964). Wikipedia "Hénon–Heiles system"(독립 출처)과 일치 |
| 운동방정식 ẍ = −x − 2xy, ÿ = −y − x² + y² | 위 H에서 유도 |
| 탈출 에너지 E = 1/6 (E < 1/6이면 원점 근처 영역에 갇힘) | 같은 독립 출처 |

1964년 논문의 특정 초기조건·에너지 값·Poincaré 수치는 원문을 확인하지 못했으므로 **쓰지 않는다**. 그런 재현은 별도의 PAPER-REPRODUCTION 단계에서 한다.
아래 초기조건은 Lab이 정한 것이다.

## 1. 두 오차를 섞지 않는다

| 층 | 비교 | 다루는 규칙 |
|---|---|---|
| **A. 반올림 오차** | binary64 궤적 ↔ **같은 이산 프로그램**의 정확 산술 궤적 | 규칙 V1 (1종 검사) |
| **B. 방법(이산화) 오차** | 정확 이산 궤적 ↔ 연속 Hénon–Heiles 동역학 | 엄밀한 상한이 없다 → 관련 2종 검사는 **REFUSED** |

**V1을 통과해도 연속 물리 궤적을 인증했다고 쓰지 않는다.** 인증되는 것은 "binary64 실행이 같은 이산 프로그램의 정확 산술 결과에서 얼마 이내인가"뿐이다.

## 2. SUT (이산 프로그램)

- 적분기: velocity Verlet (kick–drift–kick). 매 step 힘을 새로 계산한다.
- 간격 h = 1/64. 2의 거듭제곱이라 binary64로 정확히 표현된다. 따라서 h·p 같은 곱에서 생기는 오차만 남는다.
- 실행기: `numeric_core` VM의 binary64 프로필. 한 step = 33개 연산(상수 3개 포함)이다. 연산 순서는 `benchmarks/gate2a/henon_heiles.py`에 고정한다.

```
ax = (−x) − 2(x·y)       ay = ((−y) − x·x) + y·y
px½ = px + (h/2)·ax      py½ = py + (h/2)·ay
x′  = x + h·px½          y′  = y + h·py½
ax′, ay′ = 위와 같은 식 (x′, y′에서)
px′ = px½ + (h/2)·ax′    py′ = py½ + (h/2)·ay′
```

- step 수 **N = 100,000** (시간 1562.5). 두 궤도 모두 같다.

## 3. 궤도 선택 (Lab이 정함, 결과 보기 전에 규칙 고정)

모든 후보는 원점(x = y = 0)에서 출발하고, 운동량은 2의 거듭제곱 분모를 가진 수다(정확히 표현됨). 에너지는 모두 1/6보다 작다.

| 목록 | 후보 (p_x, p_y) 순서대로 | 에너지 |
|---|---|---|
| 규칙 후보 R | (1/4, 1/8), (1/8, 1/4), (1/4, 0) | 0.0391, 0.0391, 0.03125 |
| 혼돈 후보 C | (1/2, 1/4), (7/16, 5/16), (9/16, 1/8) | 0.15625, 0.14453, 0.16602 |

**분류 기준 (Lab의 유한시간 판정이며, 논문의 분류가 아니다)**
- host float로 같은 Verlet을 두 번 돌린다. 한 번은 p_x에 2⁻³⁰을 더해서 돌린다.
- N step 동안 두 상태 차이의 최댓값(성분별 최대)을 본다.
  - ≥ 2⁻⁵이면 "혼돈(측정)"
  - < 2⁻¹⁵이면 "규칙(측정)"
  - 그 사이면 "미분류"

**선택 규칙:** R에서 "규칙"으로 분류된 첫 후보, C에서 "혼돈"으로 분류된 첫 후보를 쓴다. 모든 후보의 분류는 보고서에 남긴다.
해당하는 후보가 없으면 그 사실을 보고하고, 있는 궤도로만 진행한다.

## 4. 측정 (궤도마다)

| ID | 무엇 | 종류 | 판정 |
|---|---|---|---|
| N1 | 모든 실행(전진·역방향·거울)의 **모든 binary64 연산**을 독립 채점기로 판정 (전수, 표본 아님) | — | 잘못 반올림된 단계 수 |
| BOUND | 규칙 V1 2절의 실행 오차 상한. ρ는 방식 (a) 정확 국소 오차, 상한은 위로 반올림한 float로 보관 | — | step별 상한 증가 기록 |
| HORIZON | **상태 인증 한계:** 상한의 최댓값이 상태 성분 최대 크기 이상이 되는 첫 step (규칙 V1 0절 ④) | — | step 번호 또는 "N까지 유지" |
| K1 | 시간 역전: L step 전진 → 운동량 뒤집기 → L step 역진 → (x₀, y₀, −p₀)와 비교. L ∈ {10², 10³, 10⁴, 10⁵} | 1종 (아래 근거) | PASS / FAIL / REFUSED |
| K2 | 거울 대칭: (−x, y, −p_x, p_y)에서 출발한 궤적 = 원래 궤적의 거울상 (N step 전체) | 1종 | 같음 |
| K3 | 국소 힘 법칙: **매 step**, SUT가 계산한 힘이 SUT 자신의 위치에서 정확한 −∇V와 반올림 상한 안에서 같은가 | 1종 | 실패 step 수 |
| K4 | 정확 구간 재실행: step n₀ ∈ {0, 50000, 99992}에서 binary64 상태를 정확 산술로 8 step 실행해 실제 오차가 상한 이하인가 | 1종, **SAMPLED** | 상한 위반 0이어야 함 |
| K5 | 실행기 동등성: host float로 따로 쓴 같은 Verlet 궤적이 VM 궤적과 비트 단위로 같은가 | 1종 | 같음 / 다름 |
| M1 | 에너지 보존: 기록 지점마다 H(ŝ_n) − H(s₀). 반올림 몫의 상한(상태 상자 [ŝ ± E]에서 H를 구간 평가)과 나머지(방법 오차)를 나눠 보고 | **2종** | 방법 오차 상한이 없으므로 **REFUSED**. 값은 참고 정보 |
| M2 | 유계성(E < 1/6이면 연속 궤도는 갇힘) | 2종 | 참고 정보 |

기록 지점: n = 0, 10, 100, 1000, 10⁴, 5×10⁴, 10⁵.
비용: 구성요소별 wall-clock, 최대 메모리(가능한 OS에서는 프로세스 최대 RSS), 연산 수.

### 1종 분류의 근거 (정확 산술에서 정확히 성립)

- **K1:** Verlet의 한 step은 (x, p) ↦ (x′, p′)이다. (x′, −p′)에서 한 step 하면 (x, −p)로 정확히 돌아온다.
  유도: p½ʳ = −p′ + (h/2)a(x′) = −p½, x″ = x′ − h·p½ = x, p″ = −p½ + (h/2)a(x) = −p.
  이 성질은 **힘이 위치만의 함수이면 어떤 힘이든** 성립한다.
- **K2:** a_x(−x, y) = −a_x(x, y), a_y(−x, y) = a_y(x, y)이므로 이산 프로그램이 거울 변환과 교환된다.
- **K3:** 정의상 정확히 성립한다.
- 짧은 정확 산술 실행으로 K1·K2를 확인하는 시험을 둔다.

## 5. 심은 결함 (파이프라인이 실제로 FAIL을 낼 수 있는지 확인, 10³ step)

| ID | 결함 | 잡을 것으로 예측한 검사 | 못 잡을 것으로 예측한 검사 |
|---|---|---|---|
| D1 | binary64 반올림을 버림으로 (R1과 같은 결함) | N1 | 물리 검사들(상한이 실제 국소 오차를 쓰므로) |
| D2 | drift에 p½ 대신 p를 씀 (적분기 구조 결함) | K1 | K2, K3 |
| D3 | 힘 법칙 오류: a_y = −y − x² **−** y² | K3 | **K1, K2** (위치 함수인 힘이면 시간 역전은 성립하고, 이 오류는 x 대칭을 깨지 않음) |

**미리 공개하는 맹점:** 규칙 V1에서 시간 역전과 대칭만으로는 **틀린 힘 법칙을 잡을 수 없다.** K3(국소 힘 법칙)가 있어야 잡는다.
에너지 검사(M1)라면 잡을 수 있지만, 방법 오차 상한이 없어 REFUSED다.

## 6. Gate 2A 성공 기준 (미리 정함)

| ID | 기준 |
|---|---|
| G2A-1 | 선택된 궤도 모두에서 위 측정이 **N1 전수 감사 포함**으로 끝까지 실행된다 (로컬 PC) |
| G2A-2 | N1에서 잘못 반올림된 단계가 0 (아니면 물리 판정은 모두 REFUSED) |
| G2A-3 | K4의 모든 구간에서 실제 오차 ≤ 상한. **하나라도 넘으면 상한 계산이 고장 → Gate 2A FAIL** |
| G2A-4 | K5 비트 동일 (다르면 원인을 찾기 전까지 FAIL) |
| G2A-5 | 심은 결함 D1–D3가 예측한 검사에서 잡힌다. 예측과 다르면 숨기지 않고 원인을 적는다 |
| G2A-6 | 모든 판정에 규칙상 이유가 기록된다. 2종 검사가 REFUSED인 것은 실패가 아니다 |

**혼돈 궤도에서 상한이 커져 REFUSED가 나오는 것은 실패가 아니라 핵심 측정 결과다.** 목표는 "어떤 궤도에서 몇 step까지 인증되는가"다.

## 7. 한계 (미리 공개)

- 감사 대상은 Lab이 직접 쓴 SUT다. 외부 코드가 아니다.
