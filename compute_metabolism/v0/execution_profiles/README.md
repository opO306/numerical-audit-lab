# Execution profiles

The canonical index binds every manifest. The imported AVX2 entry covers only
the authenticated Gala gradient zero-fill domain: 16 bytes, fill byte 0,
the exact caller/ELF path and the existing V1 source binding. It is rechecked
by the unchanged independent V1 checker and eight semantic negative controls.
It does not grant arbitrary memset sizes, entire-libc admission, or formal
numerical certification. Each numerical edge still passes the complete V1 gate.

Unknown IFUNC entries produce isolated OBSERVATION and CANDIDATE artifacts.
The generator cannot register authority. Explicit promotion requires a separate
independent proof bundle and a reviewed provenance anchor; adding an anchor
changes the adaptive source binding and never rewrites old evidence. Future
profiles must extend native semantics independently when existing rules refuse.
Profile ID/manifest and the live fingerprint stay fixed within a campaign.
