# 1. 구현 목표

목표는 frozen Lab semantic bundle과 physical state로부터:

```text
q = r_j - r_i
R² = q·q
R = sqrt(R²)

J_j,k = -V'(R) * q_k/R * Δt/2
J_i = -J_j
```

를 독립적으로 계산하고,

```text
scaled_J_k = 2^Fmom * J_j,k
```

가 하나의 nearest-even rounding cell에 sound하게 포함됨을 증명한 경우에만:

```text
J_raw[k]
```

를 RESOLVED로 내는 reference producer를 만드는 것입니다.

원본 executor의 impulse/J 값을 입력이나 oracle로 사용하지 마십시오.

# 7. domain admission 먼저

수치 계산 전에 physical-domain 계약을 적용하십시오.

```text
R = 0
→ singular refusal

0 < R < r_min
→ physical-domain refusal

R >= r_min
→ impulse calculation eligible
```

Domain 검사보다 zero-axis shortcut을 먼저 적용하지 마십시오.

그리고 drift guard 계약은 기존 승인 의미 그대로입니다.

```text
exact unrounded closed relative segment minimum >= r_min²
AND
stored final relative position squared >= r_min²
```

Stored rounded segment 전체 minimum을 새로 검사하지 마십시오.

# 8. sqrt enclosure

sqrt는 host float를 oracle로 사용하지 마십시오.

승인된 dyadic isqrt enclosure 방식으로:

```text
sqrt(R²) ∈ [L_R, U_R]
```

를 증명하십시오.

Singleton equality를 exact하게 입증할 수 있는 경우만 singleton을 허용하십시오.

Coarse lower bound가 0이라고 실제 R=0으로 판정하지 마십시오.

필요하면 refinement하고, finite policy에서 해결하지 못하면 UNPROVED입니다.

# 13. nearest-even proof

Scaled interval:

```text
Y_k = 2^80 * J_k
```

전체가 하나의 nearest-even cell에 들어갈 때만 raw를 확정하십시오.

Cell 의미:

```text
m even:
[m - 1/2, m + 1/2]

m odd:
(m - 1/2, m + 1/2)
```

대표 midpoint를 반올림해 결정하지 마십시오.

두 cell을 걸치면 refinement 또는 UNPROVED입니다.
