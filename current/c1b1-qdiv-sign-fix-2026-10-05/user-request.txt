# 1. F-RESOURCE-QDIV-SIGN

현재:

```python
def qdiv(self, a, b):
    if b.numerator == 0:
        raise ValueError('zero divisor')
    sign = 1 if b.numerator > 0 else -1
    return self.fraction(
        self.multiply(a.numerator, b.denominator) * sign,
        self.multiply(a.denominator, abs(b.numerator))
    )
```

에서:

```text
self.multiply(a.numerator, b.denominator)
```

뒤의:

```text
* sign
```

이 직접 Python integer multiplication이라 승인된 multiply work accounting을 우회합니다.

이를 account path로 보내십시오.

최소 형태:

```python
def qdiv(self, a, b):
    if b.numerator == 0:
        raise ValueError('zero divisor')

    sign = 1 if b.numerator > 0 else -1

    numerator = self.multiply(a.numerator, b.denominator)
    numerator = self.multiply(numerator, sign)

    denominator = self.multiply(
        a.denominator,
        abs(b.numerator),
    )

    return self.fraction(numerator, denominator)
```

실제 곱셈 전에 `self.multiply()`의 pre-operation resource check가 수행되어야 합니다.

사후에 비용만 추가 청구하는 방식으로 구현하지 마십시오.
