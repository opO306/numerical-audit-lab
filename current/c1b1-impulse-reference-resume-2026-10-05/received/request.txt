# 5. Reference producer 목표

Producer의 역할은 external J를 검증하는 것이 아닙니다.

동일한 physical state/spec으로부터 독립적으로:

```text
q = r_j - r_i
R² = q·q
R = sqrt(R²)

V'(R)

J_k = -V'(R) * q_k/R * Δt/2
```

를 enclosure하고,

```text
2^80 * J_k
```

가 하나의 nearest-even rounding cell에 완전히 포함될 때만 `J_raw[k]`를 결정하는 것입니다.

중간 R, F 또는 J를 storage grid에 먼저 반올림하지 마십시오.

전체 표현식에 대한 once-rounding 계약을 유지하십시오.
